# The Best Calculator Ever 🧮

A modern, multilingual web calculator deployed with GitHub Actions.

## Features

- ✨ **Modern UI** - Beautiful, responsive design that works on all devices
- 🌍 **10 Languages** - Support for English, Spanish, French, German, Italian, Portuguese, Japanese, Chinese, Arabic, and Russian
- ⚡ **Fast & Responsive** - Smooth animations and instant calculations
- ⌨️ **Keyboard Support** - Use your keyboard for quick calculations
- 🎨 **Advanced Functions** - Square root, square, power, and π
- 📱 **Mobile Friendly** - Works perfectly on phones and tablets
- 🚀 **Deployed with GitHub Actions** - Automatically deployed to GitHub Pages

## Supported Operations

- Basic arithmetic: Addition (+), Subtraction (−), Multiplication (×), Division (÷)
- Percentage (%)
- Square root (√)
- Square (x²)
- Power (xʸ)
- Pi (π)
- Negate (±)

### Keyboard Shortcuts

- Numbers: `0-9`
- Decimal: `.`

- Equals: `Enter` or `=`
- Clear: `Escape`, `C`, or `c`
- Delete: `Backspace`
- Percentage: `%`

## Development

This is a pure HTML/CSS/JavaScript application with no build step required.

### Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `calculator.js` - Calculator logic and functionality
- `i18n.js` - Internationalization support
- `.github/workflows/deploy.yml` - GitHub Actions deployment workflow

## Deployment

The calculator is automatically deployed to GitHub Pages using GitHub Actions whenever changes are pushed to the main branch or the feature branch.
